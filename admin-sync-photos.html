Add products from photos

A
Admin

1. Find the photos you uploaded to GitHub

This looks for photos named like gown-6-main.jpg in assets/images/mollys. It only finds photos that really exist (if you uploaded up to Gown 12, it stops at Gown 12) and skips any photo that already has a product.

2. Set each product's price, then create

Every photo gets its own row: type its own name, price (₦) and stock. To fill a whole group quickly, type one price in the group's box and press Apply to all, then change the ones that differ. Everything can still be edited later in Products.
